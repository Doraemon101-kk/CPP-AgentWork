# Windows 便携版

面向普通用户的入口是 `Start.cmd`。`launcher/guide.html` 是随包分发的静态说明页；`launcher/Start.ps1` 负责环境检查、明确确认后的模型下载、项目路径输入及命令行工作台启动。没有 Web 服务、浏览器控制接口或新增 GUI。

## 发布者构建

在配置好 C++17 工具链的终端执行：

```powershell
cmake -S . -B build_portable -DCPPPILOT_PORTABLE=ON -DBUILD_TESTING=OFF
cmake --build build_portable --config Release --parallel 2
python scripts/package_portable.py
```

MinGW 用户按需指定 `-G "MinGW Makefiles"`、`-DCMAKE_CXX_COMPILER` 和 `-DCMAKE_MAKE_PROGRAM`。MSVC 可指定 `-G "Visual Studio 17 2022"`。便携配置静态链接编译器运行库，并将运行时检查工具改为从使用者 PATH 查找，避免内嵌发布者工具路径。

打包器只收集指定文件，检查 PE 架构和 DLL 依赖、构建路径与源码隐私规则，生成 ZIP、SHA-256 和文件清单。已有 ZIP 不覆盖；重新打包使用新的 `--output` 目录。

便携包含程序、启动脚本、HTML 指南、演示项目和许可证；不含编译器、Python、Ollama、模型、私人会话、原始日志或构建缓存。

## 用户步骤

1. 完整解压 ZIP，双击 `Start.cmd`。
2. 没有 Ollama 时按提示打开官方下载页，安装后重新启动。
3. 首次下载模型前输入 Y 确认，等待进度完成。
4. 输入项目路径，或直接回车体验演示。
5. 用 `/ask` 阅读，用 `/edit` 生成提案；`/review` 预览，`/apply` 写入。

程序读代码和生成提案无需编译工具。`/configure`、`/build`、`/test` 会执行所选项目的构建逻辑，需要使用者安装相应工具链。便携版不捆绑这些工具。

`powershell -File launcher/Start.ps1 -NoGuide` 跳过指南；`-CheckOnly` 只输出环境检查，不启动服务或下载。支持 `-Port`、`-Model`、`-Root`；自动化可用 `-Execute /map` 执行一次命令后退出。

会话与修改记录保存于解压目录的 `.agent_data`。请解压到当前用户可写的文件夹；更新前保留该目录，以便恢复会话和撤销修改。
