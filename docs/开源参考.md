# 开源参考与采用范围

2026-11-21在线核验仓库与下列具体源码。借鉴工作流和接口职责，C++实现为本项目编写；未复制这些项目的源码，未声称在本机运行过它们。

| 项目 | 参考模块 | 本项目采用的设计 |
|---|---|---|
| [Aider](https://github.com/Aider-AI/aider)（Python） | [repomap.py](https://github.com/Aider-AI/aider/blob/main/aider/repomap.py) | 先给项目地图，减少模型盲目遍历。这里采用轻量词法索引，未实现Aider的Tree-sitter及排序算法 |
| Aider | [editblock_coder.py](https://github.com/Aider-AI/aider/blob/main/aider/coders/editblock_coder.py) | 搜索/替换编辑和匹配失败反馈。这里要求唯一精确匹配，先存提案，再由用户应用 |
| [mini-swe-agent](https://github.com/SWE-agent/mini-swe-agent)（Python） | [agents/default.py](https://github.com/SWE-agent/mini-swe-agent/blob/main/src/minisweagent/agents/default.py) | 对话、行动、结果反馈的循环；步骤限额和轨迹保存 |
| mini-swe-agent | [environments/local.py](https://github.com/SWE-agent/mini-swe-agent/blob/main/src/minisweagent/environments/local.py) | 记录真实退出码与输出、执行超时。这里用Windows Job Object管理进程树，命令限定为CMake/CTest |
| [Continue](https://github.com/continuedev/continue)（TypeScript） | [editFile.ts](https://github.com/continuedev/continue/blob/main/core/tools/definitions/editFile.ts) | 编辑现有文件之前先读内容。这里在程序层检查成功读取记录 |

本项目当前适合中等规模CMake学习项目：可交互处理多轮任务、跨运行恢复、提出并管理实际修改、构建验证和导出报告。没有实现IDE插件、远程沙箱、完整语义索引或大型Agent框架。

## v0.2：任务模式、流式取消、长任务记忆（已落地）

2026-11-21核对Aider模式文档与history.py源码，以及OpenCode当前API文档。OpenCode旧compaction.ts路径已失效，本轮不将该文件视为已读源码。

| 目标 | 核验来源 | CppPilot采用的做法 |
|---|---|---|
| 任务判断 | https://aider.chat/docs/usage/modes.html | 显式ask/edit/check模式；程序过滤可用工具，按模式判断完成条件；自然语言路由随后补充 |
| 历史压缩 | https://github.com/Aider-AI/aider/blob/main/aider/history.py | 按上下文预算保留近期对话，将较早部分转为摘要；摘要失败时保留原始记录，不覆盖事实 |
| 流式与取消 | https://opencode.ai/docs/api | 借鉴text.delta、tool.progress、execution.interrupted事件及interrupt操作的职责分离；本地C++实现事件队列和统一取消信号 |
| 上下文整理 | https://opencode.ai/docs/api | 借鉴compact作为独立操作；模型摘要与确定性事实账本分开，文件哈希变化使旧读取/测试证据过期 |

OpenCode服务事件流与Ollama模型响应是两个不同协议；只借鉴应用事件设计，CppPilot仍解析Ollama自己的流式格式。

实现职责：task负责模式和运行状态；context负责预算、摘要与文件版本事实；runtime负责流式HTTP及取消；界面订阅事件显示进度。实施顺序为模式→事实/记忆→流式/取消。

验收：解释类请求不会要求生成提案；文件外部变化后会重新读取；长会话保留目标及未完成项；文字和工具参数分片不混淆，完整参数校验后才执行；取消模型/测试可返回输入状态，并记录interrupted而非completed。

落实范围：借鉴Aider显式模式和旧对话摘要、OpenCode执行/中断职责。CppPilot使用进程内WinHTTP完成事件和本机取消信号，没有引入OpenCode服务端事件总线。
