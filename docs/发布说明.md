# v0.3.0 · 便携版与静态引导

新增双击入口 `Start.cmd`、命令行环境检查和随包 HTML 指南。模型缺失时明确确认后下载；支持自定义端口、模型、项目路径和仅检查模式。实际工作台保持命令行交互，没有新增 GUI。

新增便携构建配置与发布打包器：静态链接运行库、检查 PE 架构及 DLL 依赖、排除发布者路径，生成 Windows x64 ZIP 与校验清单。读代码和生成提案不要求编译工具；执行项目构建/测试仍需另装工具链。

新增启动器行为回归。Ollama、模型和编译工具不随包分发。

# v0.2.0 · 实验版

新增显式ask/edit/check模式、只读默认值、模式工具限制、流式文字与工具参数组装、Ctrl+C与跨实例取消、版本化事实账本、任务笔记、旧对话摘要及上下文预算。取消被记录为interrupted；摘要失败保留原文并使用有标记的摘录回退。修复长行源码导致词法索引正则栈溢出的问题。

行为变化：过去直接输入“修复”会要求生成提案；现在需`/edit 修复…`或先`/mode edit`。原提案应用/撤销与单次Agent入口保留。默认模型与本机服务协议不变。

新增测试覆盖模式隔离、事实失效、摘要/回退、UTF-8跨片段、工具参数分片、截断流拒绝执行、请求及进程树取消。真实模型验收结果和发布验证范围见发布验证文档。

# v0.1.0 · 实验版发布说明

## 发布范围

Windows本地C++ Agent工作台，支持持续对话、项目/符号候选索引、9个模型工具、修改预览/应用/撤销、CMake/CTest与报告。适合学习和可信本地项目，尚未逐行人工审阅全部AI生成代码。

## 本轮发布整理

- 编译器/生成器从环境或参数选择，构建输出统一到build/bin。
- 构建检查使用本次CMake配置产生的工具链信息，不再写死开发者路径。
- Ollama复用现有服务或从PATH/标准安装位置/参数启动；默认使用标准端口11434。
- CTest传入实际可执行文件，测试支持自定义和多配置构建目录。
- 补充MIT许可证、第三方声明、AI开发说明、Windows CI、脱敏演示摘要和源码打包。

## 已知范围

本机实际验证Windows/MinGW。MSVC配置与CI已编写，上传前尚无远端CI结果。非ASCII构建路径、语义索引、恶意并发路径替换等限制见README。

## 发布内容

源码包包含原始源码、许可证、固定版本JSON依赖、测试、无私人内容的样例和文档。
不包含模型、Ollama、可执行文件、编译缓存、会话、原始日志、本机报告或学习档案。
本次只完成本地发布准备，没有创建远端仓库或上传。
