让本地模型帮你读代码

下载、解压、双击 Start.cmd。所有操作在终端中完成。

1 · 准备本地模型

安装 Ollama for Windows，然后双击 Start.cmd。启动脚本会检查服务和模型，缺少模型时先征求你的确认，再显示下载进度。

默认模型约 2.5 GB，建议 16 GB 以上内存。首次下载需要联网；模型准备好后，对话由本地服务处理。

2 · 选择要看的项目

回到终端，粘贴项目文件夹路径；直接按回车，使用自带的加法错误演示项目。

便携包已经包含程序，无需编译。读代码和生成提案不要求 CMake、Python 或编译器；运行项目编译与测试，需要另装 CMake 和适合该项目的 C++ 工具链。

3 · 先问，再改

/ask 看看这个项目，入口和加法函数在哪里？
/edit 读取加法函数和测试，生成修复提案。
/changes
/review 提案ID
/apply 提案ID

把“提案ID”换成程序给出的编号。默认只读；生成提案时源码保持原样，执行 /apply 后才写入。

配置好编译环境后，可用 /test 检查结果；/undo 提案ID 撤销对应修改。

遇到问题

找不到程序：下载 Windows 便携包并完整解压，别直接在 ZIP 内运行。GitHub 的 Source code 是源码包，需要自行编译。

模型服务无法连接：先启动 Ollama，再运行启动脚本。自定义端口可运行 powershell -File launcher/Start.ps1 -Port 11435。

编译或测试失败：检查是否安装 CMake 和 C++ 编译器，以及它们是否在 PATH 中。查看终端里的实际错误输出。

本页是静态指南，没有上传表单或外部脚本。关闭此页不影响终端工作台。退出输入 /exit；当前任务可用 Ctrl+C 中断。会话与修改记录留在解压目录的 .agent_data 中。项目采用 AI 辅助开发，修改请先预览。
